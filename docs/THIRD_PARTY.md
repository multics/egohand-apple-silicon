# Third-party resources

The MIT license covers this repository's original integration code. It does
not change the licenses of downloaded source code, models or assets.

| Resource | Source and license information |
| --- | --- |
| Isaac Capture / EgoPost | [NVIDIA Isaac Capture](https://github.com/NVIDIA/IsaacCapture); pinned files declare OpenMDW 1.1. The fetch script retains upstream LICENSE files. |
| EgoHand-v1 | [NVIDIA model card](https://huggingface.co/nvidia/EgoHand-v1); read the model terms before download. |
| DINOv3 | [Meta DINOv3](https://github.com/facebookresearch/dinov3); separate DINOv3 license. |
| SOMA-X / MHR assets | [NVIDIA SOMA-X](https://huggingface.co/nvidia/SOMA-X), [Meta MHR](https://github.com/facebookresearch/MHR); read the applicable asset terms. |
| SOMA Python package | `py-soma-x==0.3.0`, Apache-2.0; distributed separately. |
| RT-DETR hand detector | [NVIDIA detector model card](https://huggingface.co/nvidia/RT-DETR-Hand-Detector-v1). |

Weights, upstream source trees, camera inputs and generated model derivatives
are not included in Git. The fetch scripts record fixed revisions. Keep
upstream notices when you redistribute any third-party material.
